# 力学实验数字化平台

本系统用于实验后的断口采集、原设备数据归档、课堂操作记录和报告评阅。安全门联锁、实验控制与原始采集由拉力设备原有客户端负责；平台不控制设备启动、暂停或停止。

## 当前现场流程

新下发任务统一使用“拉伸压缩实验”，包含钢的拉伸、铸铁的拉伸、钢的压缩、铸铁的压缩四个试验子项。每组共用一个任务与课堂操作成绩，四项分别保存试件信息、设备数据、曲线和试件形貌照片。学生在现场实验页面切换子项，明确选择相应设备文件；四项采集完成后提交综合操作记录，每名学生提交一份综合实验报告并获得一个最终报告成绩。历史独立试验任务保持原有记录方式。

1. 教师可一次或分批上传本学期的全体学生，名单累计保存；上传即创建可登录账号，不要求先分组或下发实验。模板包含学号、姓名、专业、班级，兼容旧的三列模板；重复学号更新资料，保留密码及实验数据，旧模板不清空专业。下发页按专业、班级、安排状态及姓名/学号筛选学生，勾选跨筛选与分页保留。按专业及班级均衡分组，预览中可调整成员；下发时创建本课次小组，先固化历史成员快照，不移动未勾选的学生。未安排学生登录后仅看到空任务页和个人账号入口。旧版已被替换的导入范围不会自动推断归属，教师可重新导入对应名单。
2. 任务下发后为“待开课”，学生可登录、修改密码并查看安排；由下发教师点击“开始实验”后，该课次所有小组才允许采集。旧任务兼容原有开放状态。教师确认各组操作成绩后关闭该组采集，全部小组关闭后课次显示“已结束”。这里的开课只开放平台采集页面，不启动仪器。
3. 本次名单调整新增可空字段 `students.major VARCHAR(128)`。Spring Boot 启动时自动补齐，Node 初始化脚本也兼容；已有账号及任务无需重建。
3. 学生在原设备客户端完成装样、关门联锁、实验与原始数据采集，按规程拆样并采集断口照片。
4. 学生导入本次设备导出的 CSV、TXT、TSV、XLS 或 XLSX 文件，明确选择数据起始行、力列、位移列和力单位。
5. 全部子实验采集完成后，教师确认本次扣分；学生查看扣分项目、原因和操作分，选择接受成绩并提交综合操作记录，或申请重做。教师批准后建立独立重做记录，保留原实验数据。成绩确认后再提交个人 Word/PDF 报告。

## 启动生产版本

生产使用的是 Spring Boot + Vue 版本：

```powershell
# 终端 1：断口分析服务
cd fracture-service
python -m uvicorn app:app --host 127.0.0.1 --port 8090

# 终端 2：构建并启动后端
cd backend
mvn package
java -Dfile.encoding=UTF-8 -jar target/lab-digital-platform.jar

# 终端 3：前端开发服务
cd frontend
npm install
npm run dev
```

打开 `http://localhost:3780`。部署到服务器时可先运行 `npm --prefix frontend run build`，再运行 `mvn -f backend/pom.xml package`；构建后的前端静态文件会随 Spring Boot 包一起提供。

也可运行 `scripts/start-spring-vue.bat` 启动三个服务。

Windows 服务器一体化部署包（前端 + Java 后端 + Python 断口分析）可用以下命令生成：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/package-deploy.ps1
```

压缩包生成在 `artifacts` 目录。服务器需安装 Java 21+、Python 3.10+，并配置 MySQL。
解压后将 `.env.example` 复制为 `.env` 并填写服务器数据库配置；升级时保留服务器原有 `.env` 和业务数据。
双击 `start.bat` 同时启动断口分析和 Java 服务，并检查两个 HTTP 接口就绪；双击 `stop.bat` 同时停止。
首次启动会创建 Python 虚拟环境并联网安装依赖，后续直接复用。
通过 `http://服务器IP:8586` 访问，前端已内置到 JAR，不需要另开 Vite。
现有 Nginx 可以继续反向代理到 8586，详见包内 `DEPLOY.txt`。部署包不包含 JDK、Python、MySQL 和生产数据。

## 已实施功能

- 实验记录以“每次实验”为单位，保存成员快照、试件编号、设备编号、断口照片、设备原始数据及归档快照。
- 断口可先采集，原设备数据可稍后补齐；归档时才检查完整性。
- 教师可在手机或平板上记录课堂扣分、填写依据、撤销纠错、锁定课堂记录，并独立保存最终分和评语。
- 学生上传 Word/PDF 后保留原件、SHA-256 校验值、服务端提交时间和版本回执。扫描件或解析不完整的报告会提示人工查看，不会直接按内容缺失扣分。
- 教师可配置扣分清单、报告必需章节、组内相似度阈值和补做时间窗口；重做生成独立实验记录，教师决定采用哪次成绩。
- 断口分析使用拍摄质量和宏观轮廓线索，结果必须由教师复核。报告 AI 建议和查重结果均不自动覆盖教师最终分。

首次上线前，教师应在“教学规则与学校模板”中录入最终扣分项目与分值，并上传学校正式报告模板。OCR 为可选能力：如果需要识别扫描件，请在环境变量中设置 `REPORT_OCR_COMMAND` 为本机 Tesseract 可执行文件路径。

## 账号（演示）

| 身份 | 账号 | 密码 |
|------|------|------|
| 教师（固定） | `teacher` | `123456` |
| 学生 | 学号（上传名单后生成） | 新建学生初始密码为完整学号 |

学生登录后可通过右上角个人菜单修改密码，需输入原密码。重复导入名单不会重置已有学生密码；升级不会改变已有账号的密码。修改密码后保留当前标签页登录，其他已有登录失效。

教师在“学生名单”中可按行查看或隐藏学生登录密码，仅教师专用接口返回密码，普通名单接口不返回密码。登录仍使用 scrypt 校验；为支持查看，新增 `student_password_secrets` 表单独保存 AES-GCM 加密副本。新建、学生改密、教师重置时同步保存。历史账号若能核验密码仍为学号即可查看，其余历史密码必须重置后才能查看。

首次启动会在工作目录的 `config/student-password.key` 自动生成密码加密密钥，也可通过 `STUDENT_PASSWORD_KEY_FILE` 配置路径。密钥不得提交 Git 或随部署包分发；迁移、升级和数据库备份时须保留并妥善保管原密钥。已有加密密码但密钥文件丢失时，服务会拒绝启动，需恢复原密钥。不要使用学生用于其他系统的密码作为本系统密码。

## API 概览

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/meta` | 实验目录、教师、小组 |
| POST | `/api/auth/login` | 登录 |
| GET | `/api/session` | 当前会话快照 |
| GET/POST | `/api/tasks` | 任务列表与下发 |
| GET/POST | `/api/workflow/*` | 实验记录、原始数据、照片、课堂扣分、报告、复核与重做 |
| GET | `/api/assistant/status` | AI 评阅服务状态 |

旧版 Node/Express 原型仍在仓库中供对照；现场应使用上面的 Spring Boot + Vue 启动方式。

## 数据库配置

默认连接配置写在 `.env`：

```text
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=lab_digital_platform
```

后端首次启动会补齐新表，不会清空旧有数据。旧的组报告和个人报告会在首次进入新的实验记录时保留为升级前快照；升级前曲线不会被标注为本次从设备导入的数据。
