## 本轮实现

| 环节 | 实际行为 |
| --- | --- |
| 下发任务 | 勾选本次参与小组和试验子项；其他未分组学生不再阻塞下发。每次下发生成独立 taskId，保留此前记录。 |
| 学生身份 | 名单沿用学号、姓名、班级；新实验成员保存班级快照；任务中心展示组员。 |
| 数据导入 | 明确选择厂商数据文件，或上传 CSV/Excel、预览并指定数据行、列和力单位。保存原文件；拦截相同文件跨实验记录复用。 |
| 曲线 | 保留力—位移曲线；按录入的截面积、标距或压缩试件原始高度换算应力—应变。尺寸缺失时不生成假定尺寸的曲线。设备位移换算的应变标记为估算。 |
| 试件与断口 | 大图与分析结果左右布局；移除手填试件编号、设备编号和实验时间；支持浏览器摄像头选择、拍摄、上传和原图下载。离开采集页关闭摄像头。 |
| 现场扣分 | 默认 100 分，教师记录或撤销扣分。发布操作成绩后，学生逐人确认或提出异议；教师查看确认名单。改分或重新开放课堂会使旧确认失效。 |
| 操作记录 | 小组资料提交与个人成绩确认分开；按实际安排的子项检查资料，明确展示缺项。提交前获取最新记录版本，避免后台扣分刷新导致旧版本提交失败。 |
| 个人报告 | 允许提前保存附件草稿；正式提交须资料归档且本人确认最新操作成绩。报告保存版本、个人确认和成绩版本快照。 |
| 教师报告列表 | 按课次汇总所有组员；可搜索姓名、学号、班级、小组，按状态筛选；显示提交/批阅时间、教师、分数、相似度及操作。 |
| 批阅 | 左侧学生列表、中间报告原文、右侧辅助批阅与人工评分；支持批改中状态、退回、版本选择、原文件和批阅记录下载。 |
| 查重 | 同课次不同学生的报告比较；双栏提取文本、相同片段定位与高亮，支持切换到原始文档预览。相似度不自动修改教师成绩；无有效文本不显示为 0%。 |
| 历史与重做 | 学生可切换历史课次；补做保持独立实验尝试；报告重交使用版本号。重做名单展示相关班级的全部学生，不再隐式只显示首个班级。 |
| 首页进度 | 任务中心从实际实验记录、资料提交和个人报告状态派生进度，避免旧流程状态造成显示不一致。 |

## 上课时的操作

1. 教师导入名单、分组，勾选参与小组与本次试验项目后下发。
2. 学生在任务中心查看组员；使用厂商软件完成试验后，在平台选择对应数据文件，填写计算尺寸。
3. 学生拍摄或上传试件照片，查看分析结果。全部安排的项目采集完成后，一名组员提交小组操作记录。
4. 教师记录扣分，课末对各组点击“发布操作成绩”。每名学生核对明细后点击“确认本人成绩”；有问题时“提出异议”。
5. 教师如需纠错，重新开放课堂并修改扣分，再发布；受影响的学生重新确认。
6. 学生分别提交个人报告。教师在对应课次查看全班报告，批阅、查重或退回。
7. 下次实验下发新任务；同课次重做使用“重做安排”；修改报告使用退回后的新版本。

子实验只包含“数据采集”和“试件与断口”两个处理步骤，不单独生成操作记录或成绩。完成本课次安排的全部子实验后，系统开放唯一的“本课次最终操作记录”，其中汇总各子实验的数据、曲线、照片和分析，并使用本课次统一的扣分明细与操作总分。

## 验证范围和保留边界

- 后端使用独立 H2 测试库验证逐人确认、改分失效、未确认提交拦截、试验子项、尺寸保存、跨组文件重复、课次历史、报告比较与首页状态。不会向当前课堂写入测试扣分或测试报告。
- 浏览器实际登录教师、学生账户，验证任务选项、历史记录、报告原文预览、桌面三栏、移动端无横向溢出和页面脚本错误。查重双栏布局另以隔离的 API 测试样本验证；真实文本比较由后端测试覆盖。
- “批阅记录”是单独导出的 DOCX，包含评分、评语和提取正文，不是对原文件版式做原位批注。
- 高亮基于提取文本的字符位置，尚未实现 PDF/Word 原版页面上的坐标批注。模板共用文字可从配置的排除文本及模板中排除；当前查重属于文本片段相似度检查。
- 当前厂商数据目录没有可选文件，尚未完成试验机现场文件联调；真实 USB 摄像头需接入后验证。摄像头代码和设备选择入口已完成。
- 现有断口分类沿用形貌规则，尚未以标注实验样本验收准确率。Dify 辅助批阅当前未配置，人工批阅可以使用。
- 历史任务保留原来安排的四个子项，不自动删改课堂要求；新任务可按实际课次选择子项。历史数据缺少计算尺寸时，不反填默认值。
